Playing Patch Arcade

Patching

  • Drag from any jack to another to patch a cable. Valid targets light up.
  • Output → input only. Audio to audio, CV to CV. A new cable into an audio input replaces the old one; To Host and CV inputs sum.
  • Patching a left output into a left input wires the right pair too.
  • Hold Shift (or press ✂) and click a cable to remove it. Double-click a jack to clear it.
  • The small square on a module solos its cables.

Playing

  • Start audio, then pick sources for In 1–3: demo instruments, your mic/line input, or an audio file.
  • Tap a die to roll a random chain for that input; the red ✕ clears it. Hand-patched cables are never touched.
  • Knobs: drag up/down (Shift = fine), mouse wheel, arrow keys. Double-click resets.
  • Cables tint by route: 1 2 3, CV.

Staying clean

  • Every module is bounded and oversampled where it distorts; feedback cables lose a little top end each pass, so loops darken instead of fizzing.
  • The output passes a 15.5 kHz low-pass, the Shrill Guard, a runaway leveler, a silence gate and a brickwall limiter at −1 dBFS.
  • Panic clears every buffer if a loop gets away from you.
