Playing Patch Arcade

There is no oscillator here. Strike sends one single-sample impulse into the rack; everything you hear after that is the patch listening to itself through delays, filters and nonlinearities: a bounded feedback loop hunting for a stable shape and never quite finding one. The knobs don't shape a sound. They shape the conditions a sound must satisfy in order to exist.

The conditions

  • Strike: one impulse into every From Host input and every loop. A cable that closes a new loop strikes it too.
  • Life: how strongly loops sustain themselves. At 0 nothing is held: a strike rings out and dies.
  • Breath: how far and how slowly every loop swells and recedes. No two breaths are alike.
  • Unrest: how soon a tone a loop has settled on is carved away, sending it hunting again.
  • A loop's panels glow with the energy living in it; the Strike button glows with the whole rack's.

Patching

  • Drag from any jack to another to patch a cable. Valid targets light up.
  • Output → input only. Audio to audio, CV to CV. A new cable into an audio input replaces the old one; To Host and CV inputs sum.
  • Patching a left output into a left input wires the right pair too.
  • Hold Shift (or press ✂) and click a cable to remove it. Double-click a jack to clear it.
  • The small square on a module solos its cables.

Playing

  • Start with a factory patch (click the purple display). The first four groups need no input at all.
  • Tap a die to roll a random loop for that route; Fdbk sets the chance of extra tangle. The red ✕ clears it. Hand-patched cables are never touched.
  • In 1–3 default to Impulse only. Demo instruments, your mic/line input or an audio file are optional, for using the rack as an effect (the Input FX patches).
  • Knobs: drag up/down (Shift = fine), mouse wheel, arrow keys. Double-click resets.
  • Cables tint by route: 1 2 3, CV.

Staying clean

  • Every module is bounded and oversampled where it distorts; feedback cables lose a little top end each pass, so loops darken instead of fizzing.
  • The output passes a 15.5 kHz low-pass, the Shrill Guard, a runaway leveler, a silence gate and a brickwall limiter at −1 dBFS.
  • Loops are held below a ceiling set by Life, and the loop-loss filters keep them out of the sub-bass and away from fizz.
  • Panic clears every buffer: the rack falls silent until the next Strike.
